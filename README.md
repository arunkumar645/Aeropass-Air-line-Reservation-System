# 📖 Overview

**AeroPass** is a desktop-based Airline Reservation System developed using **Java Swing** and **MySQL**. The application provides an intuitive graphical interface that enables users to search flights, reserve seats, enter passenger details, complete bookings, and generate digital tickets.

The system demonstrates desktop application development, object-oriented programming, database connectivity, and reservation workflow management while delivering a seamless airline booking experience.
